# en-GB — British English

## Norm

British spelling, British vocabulary, British punctuation. The app's locale tag is `en-GB`; American English is a defect, not a variant.

## Spelling

| British | Never American |
| --- | --- |
| colour, favour, honour | color, favor, honor |
| centre, theatre, metre | center, theater, meter |
| organise, recognise, realise | organize, recognize, realize |
| defence, offence | defense, offense |
| licence (noun), practise (verb) | license (noun), practice (verb) |
| travelled, cancelled, modelling | traveled, canceled, modeling |
| catalogue, dialogue | catalog, dialog |
| programme (plan, TV) | program (except a computer program) |
| grey | gray |
| jewellery, kerb, tyre | jewelry, curb, tire |

## Punctuation

- Dialogue in single quotes: `‘Where is the hat?’ asked the girl.`
- Punctuation goes inside the closing quote when it belongs to the speech.
- No Oxford comma by default. Use one only to prevent a real ambiguity.
- Dates: `3 March 2026`.
- Times: `3pm`, `3.30pm`.

## Numbers in narration

- Spell out one to ten: `three pages`, `seven years`.
- Numerals for dates, ages in a factual line, and larger counts.

## Examples

Source: "Ele é um menino de uma perna só, pele escura, gorro vermelho e um cachimbo na boca."

Good: "He is a boy with only one leg. His skin is dark, he wears a red cap and he has a pipe in his mouth."

Bad: "He is a one-legged boy of dark complexion, sporting a red beanie and a pipe." (American `sporting` idiom, `beanie` is wrong for the tale's cap, and the sentence packs four ideas).
